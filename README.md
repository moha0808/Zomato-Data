# Zomato Data Analysis

## 📌 Project Overview
This project focuses on analyzing **Zomato restaurant data** to uncover insights into dining trends, pricing, and customer preferences. The goal is to provide a comprehensive view of the culinary landscape through data-driven visualizations and statistical analysis.

## 📊 Key Features
* **Data Cleaning:** Handling missing values and formatting currency/location data.
* **Exploratory Data Analysis (EDA):** Visualizing rating distributions, price ranges, and cuisine popularity.
* **Geographical Mapping:** Analyzing restaurant density across different cities/localities.
* **Insights:** Identifying factors that contribute to high user ratings and visibility.

## 📂 Project Structure
```text
├── data/               # Raw and processed datasets
├── notebooks/          # Jupyter notebooks for analysis
├── visualizations/     # Exported charts and graphs
└── README.md           # Project documentation
```

## 🚀 Getting Started

### Prerequisites
To run the analysis locally, you will need:
* Python 3.x
* Pandas
* Matplotlib / Seaborn
* Jupyter Notebook

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/moha0808/Zomato-Data.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Zomato-Data
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
